A token launch radar over DefiLlama's sealed snapshot: protocols that record no token, ranked by a value model fitted on the protocols whose token already trades, each with a costed farm plan and a static dashboard (no network, no framework).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input path/to/snapshot.json
```
